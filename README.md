# gh-pages — solo la página de prueba del widget

Esta rama es huérfana a propósito: no comparte historia con `main` ni con
`multi-tenant-y-documentacion`, y solo contiene estos dos archivos. Es la
fuente de https://monkeyotbz.github.io/crm-ventas/ — un doble de
hellominus.com para probar `widget/candy-chat-widget.js` sin depender de
un servidor local ni tocar el repo de hellominus.com.

No editar acá directamente: los archivos fuente viven en `widget/` en las
ramas de trabajo (`main` / `multi-tenant-y-documentacion`). Para actualizar
esta página, copiar de ahí y volver a pushear a `gh-pages`.
